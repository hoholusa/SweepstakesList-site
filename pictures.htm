Main Screen Options Screen Filter Screen

The Main Screen has a List View and a Detail View. The List View is used to browse through sweepstakes entered and due for entry. When you select a sweepstakes in the List View, you get its details in the Detail View. From the Detail View you can also open the sweepstakes entry page and rules page in your browser.

On the Options Screen you can change settings for multiple Sweepstakes List features. They include Title, Default Pre-Fill, Pop-Up Calendar, Players List, Default Player Name, Data Cleanup, Columns, Web Browser and other options.

The purpose of the Filter Screen is to filter sweepstakes in the Main Screen List View, view expired sweepstakes, load only sweepstakes due for entry, and sort sweepstakes.
